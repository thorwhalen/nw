nw.renderers._common

Helpers shared by render strategies — uploads, trim/pad, prompt build.

nw.renderers._common.download_to(url: str, dst: Path) → Path[source]

Download a URL to dst (creates parent dirs). Returns dst.

nw.renderers._common.loop_image_with_audio(image: Path, audio: Path, target_s: float, dst: Path) → Path[source]

Build an mp4 that holds image for target_s seconds with audio as the soundtrack. ffmpeg-only; no fal calls.

nw.renderers._common.trim_or_pad_video(src: Path, target_s: float, dst: Path) → Path[source]

Cut/pad a video to exactly target_s seconds.

Mirrors muvid.renderers._common.trim_video_to_duration (Phase 0.6 fix). Within 50ms → copy. Longer → cut via mixing.video.Video. Shorter → pad with held last frame + audio silence via ffmpeg tpad/apad. Falls back to a copy on any error so the caller always gets some file.

nw.renderers._common.upload_local_file(path: Path) → str[source]

Upload path to fal.ai’s storage and return the temp URL.

fal_client must be installed; raises ImportError otherwise (with a clear message — most call sites need fal anyway).
