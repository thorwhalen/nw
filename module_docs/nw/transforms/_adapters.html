nw.transforms._adapters

Built-in Transform adapters — imported for their registration side effects.

Importing this package registers the adapter Transforms with nw.transforms.transforms. Currently:

  • render_strategy — wraps each of the 5 existing nw.renderers strategies as a shot_to_render_result.fal.* Transform, proving the Transform abstraction against working code without duplicating any rendering logic.
